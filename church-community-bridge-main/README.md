# Church Community Bridge

I want to build a mobile app for a church as an installable PWA for regular congregation members. Build it around sermons (with audio and video streaming), events calendar and RSVPs, prayer requests, digital giving, and a community hub featuring dedicated groups (such as youth groups, women's groups, and men's groups) where members can connect, share ideas, and post discussions.

This project was built with [Lovable](https://lovable.dev).
